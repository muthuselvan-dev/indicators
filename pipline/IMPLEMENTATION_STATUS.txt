MISSING 34 INDICATORS - SINGLE COPY/PASTE PACKAGE

This archive includes 34 indicator-named .go files and category types.go files.
It is NOT a claim of 34 production-ready, QuantMan-matched implementations.

All packages compile in an isolated harness using the supplied core.MarketCandle interface.
Existing pipline.go, trend/, momentum/ and candlestick/ are not included or modified.

KNOWN LIMITATIONS:
- Some indicator files deliberately return constructor errors because the required
  QuantMan-specific external inputs, strategy state, or signal semantics are unavailable.
- Several candle-reference and channel implementations are documented local interpretations,
  not independently verified QuantMan parity.
- Moving Average For RSI requires further RSI-series integration and is not ready.
- Opening Range Breakout is a rolling-window approximation, not a verified session ORB.
- Formula references are incomplete for QuantMan-specific nodes.
- No complete numerical golden-data tests have been performed.

This is a consolidated code DELIVERY / REVIEW BUNDLE, not a finished Stage 1 release.
